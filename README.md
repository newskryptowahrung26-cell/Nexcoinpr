# NexcoinPR — Crypto & Forex PR Agency Platform

Official web platform for **NexcoinPR** — a premium international PR and media services agency specializing in cryptocurrency, blockchain, Web3, forex, fintech, and financial communications.

## Features

- **Semantic HTML5 & Vanilla JavaScript**: Fast loading, zero bloat, mobile-first responsive design.
- **Dedicated Content Architecture**: Single unified content hub under `/news/` and evergreen guides under `/news/guides/` (zero `/blog/` pages).
- **Comprehensive Service Coverage**: Crypto PR, Forex PR, Blockchain PR, Web3 PR, Fintech PR, Financial PR, and Press Release Distribution.
- **Dedicated Press Release Hub**: Structured `/press-releases/` section with prominent commercial disclosures.
- **SEO & AI Search Engine Optimized**:
  - Valid JSON-LD schemas (`Organization`, `Service`, `NewsArticle`, `Article`, `FAQPage`, `BreadcrumbList`)
  - XML Sitemap Index (`sitemap.xml`, `sitemap-pages.xml`, `sitemap-news.xml`, `sitemap-press-releases.xml`)
  - RSS 2.0 Feeds (`feed.xml`, `feed-crypto.xml`, `feed-forex.xml`, `feed-press-releases.xml`)
  - AI Context Manifests (`llms.txt`, `llms-full.txt`)
  - Search engine crawler directives in `robots.txt`
